Use the reviewed `eeglab_*` tools for EEG work in the cloud MATLAB session.

Start with read-only intake: initialize, load, QC, information, events and history. Use project planning and event semantics audit before high-risk processing. Unknown, boundary, impedance and segment-only markers are not confirmed condition triggers.

Run method preflight and satisfy its critical requirements. An explicit override must record its reason and missing requirements. Preserve raw data, write derivatives to the cloud artifact directory, record parameters and stop on a failed child gate. ICA classifications support review and are not automatic removal rules.

Use plugin checks to distinguish availability from supported execution. Indexed plugins and advanced methods remain guidance-only. Lock subject-level processing and design variables before STUDY statistics; precompute the selected measure and document pairing, alpha and correction.

Use protocol export to retain recording facts, event semantics, processing parameters, plugin status, gates, source claim IDs, overrides, output paths and limitations. Read `eeglab_official_claims` for the versioned official source map. Scientific outputs are not clinical diagnoses.

Use the repository's GitHub cloud workflow. No desktop installation or client configuration is required. Consult `references/` for event, ICA, acquisition, source, STUDY and reporting policies; consult `docs/` for official method/plugin/risk/support matrices and the complete MATLAB tool catalog.
